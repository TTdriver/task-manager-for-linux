## 0.1.0 — 2026-10-04

- First working Linux desktop monitor with a Windows-inspired dark interface.
- Live CPU, memory, disk throughput, and network throughput graphs.
- Searchable and sortable process list with graceful End task.
- Storage capacity view and pause/resume display updates.
- Per-user installation with desktop and applications-menu launchers.

Validation: live sampling, all pages, search, numeric sorting, pause, resizing, terminating a disposable child process, and isolated installer/launcher validation passed.
